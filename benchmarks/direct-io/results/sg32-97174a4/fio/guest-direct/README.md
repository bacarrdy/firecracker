## Guest direct I/O

Commit `97174a4`, Async and Writeback. Both host modes negotiated 32 segments. Guest fio used `direct=1` against the same disposable block device backed by a 1 GiB file on ext4, on a consumer Kingston KC2500 NVMe. Three rounds per mode, with the mode order reversed in round two. The main phases transfer 256 MiB each.

Cells are **MiB/s / IOPS / p99 ms**. Write and mixed rates use elapsed time from launching fio through the final guest fsync, including close-time writeback. The p99 is for the individual data operation. Both directions in a mixed phase use the same throughput clock.
