# Historical local NVMe measurements

Consumer Kingston KC3000 without hardware power-loss protection.
These are separate runs of the listed binaries across multiple sessions and
thin volumes. All used Async and Writeback. The table shows the median of four
runs per mode. Each cell gives **active fio MiB/s / IOPS / p99 ms**. Buffered
write latency includes writes that completed against host RAM. The separately
timed flush and backing-device I/O counts are in the [sample CSV](local-nvme-samples.csv).
