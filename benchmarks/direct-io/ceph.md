# Historical Ceph RBD measurements

The first two columns use an earlier single-segment PR binary. The other
columns are separate scatter-gather builds that use direct I/O. These data
describe the listed binaries and sessions. Each cell lists both active fio
samples in seed order as **MiB/s / IOPS / p99 ms**, with final fsync in
the [sample CSV](ceph-samples.csv). There are two trials per cell and the
spread is large. The rows do not establish a general ranking.
